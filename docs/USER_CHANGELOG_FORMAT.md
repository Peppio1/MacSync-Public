# Note di rilascio per l'utente

Ogni nuova release stabile deve contenere una sezione Markdown `## Novità per l'utente`, con al massimo sei punti `- ` brevi, in italiano (massimo 240 caratteri ciascuno), senza HTML o collegamenti. La stessa sintesi deve comparire nelle note del feed Sparkle. Includere solo modifiche effettivamente validate al momento del rilascio. Le note GitHub sono informative e non autorizzano l'installazione. La prima conferma è Annulla/Aggiorna; dopo Aggiorna restano il backup e il controllo indipendente della firma Sparkle.
