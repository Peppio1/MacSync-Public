# MacSync v0.18.13

- La rettifica prosegue con le voci indipendenti quando una rinomina resta in sospeso. Le voci collegate, comprese le cartelle che contengono una voce bloccata, restano nel lotto.
- Nomi incompatibili mostra l’attesa prima dell’avvio, una barra con le voci esaminate e il primo motivo di arresto di una rinomina.
- Impostazioni include **Ripristino MacSync → Azzera tutti i dati…**. Dopo conferma e chiusura, alla riapertura vengono azzerati le impostazioni, il database, la coda, i registri e i backup interni. I file nelle cartelle sincronizzate e le credenziali del Portachiavi restano intatti.
- La rettifica su una destinazione SMB resta da verificare nella configurazione effettiva.
