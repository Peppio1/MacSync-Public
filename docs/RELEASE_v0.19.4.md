# MacSync v0.19.4 — build 202

## Novità per l'utente

- Diagnostica estesa delle fasi di copia, verifica archivio e reattività dell’interfaccia.
- Riconciliazione della coda e riutilizzo dei metadati della verifica, con controlli di sicurezza invariati.
- Informazioni aggiuntive nella coda sulle operazioni legate alle rettifiche dei nomi.
- Anteprima delle novità prima della conferma di aggiornamento.
- Ripristino volontario alla v0.19.3 tramite il pacchetto firmato originale, senza sostituire il database.

La verifica rapida non legge il contenuto dei file. I nomi SMB non identificabili con certezza restano protetti; il collaudo operativo con Windows Server reale resta necessario. Il motore Rclone rimane invariato.

Compatibile con Apple Silicon e Intel, macOS 13 o successivo.
