# Comparative performance laboratory v0.19.4

The opt-in workflow runs the actual mounted-folder copy worker with the same pinned Rclone v1.76.0 helper and the same synthetic 960 MB fixture on the tested v0.19.3 commit and the candidate. Six folders, each with four 2.5 MB JPG files, four 25 MB DNG files, and one 50 MB PSD file. Contents are deterministic pseudorandom bytes, not real photos. Three trials per version, alternating order, fresh empty destination and database per trial. Release-mode tests, copy-cycle wall time (not only the transfer), operational QUICK audit wall (including queue reconciliation) and phase timings, byte-for-byte SHA-256 comparison outside timed phases. No timing threshold or guaranteed gain; compare medians and dispersion, distinguish warm-cache effects. The loopback Samba case is a real macOS SMB mount, not the production Windows/VPN path. The small fixture does not establish performance for 207,000 items or 350 GB. Main, stable releases and actual transfer flags remain unchanged. No production files or credentials are used. Trigger via benchmark-v0.19.4; artifacts contain numeric measurements only.
